# Titanic Survival Prediction – Custom Decision Tree

A Machine Learning project using the Kaggle Titanic dataset.

## Overview

This project implements a Decision Tree classifier from scratch using Python and Pandas, without relying on Scikit-learn's Decision Tree implementation.

## Features

- Entropy and Information Gain
- Numerical and categorical feature splitting
- Missing value imputation
- Feature engineering:
  - FamilySize
  - IsAlone
- Maximum depth control

## Dataset

Dataset source: [Kaggle Titanic Competition](https://www.kaggle.com/competitions/titanic/data)

Please download the original dataset from Kaggle and place the files inside the `data/` directory.

The original dataset is not included in this repository.

## Results

- Kaggle Public Score: 0.77511
- Model: Custom Decision Tree
- Maximum Depth: 6
